how to create the token (one-time, 2 minutes)
  1. Log into GitHub as IS-2020 (the account that owns the website repo)
  2. Go to Settings → Developer settings → Fine-grained tokens → Generate new token
  3. Name: car-portal · Expiration: 90 days (or custom)
  4. Repository access: Only select repositories → ishaansamantraywebsite
  5. Permissions → Repository permissions → Contents: Read and write (leave everything else No access)
  6. Generate, copy the token, paste it above, hit connect
⚠ Never share this token or paste it anywhere else. It only lives in this browser's localStorage.
